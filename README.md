# Avel — утилита для Windows 10/11

[![GitHub Release](https://img.shields.io/github/v/release/gajsin/avel?include_prereleases&style=flat-square&color=22c55e)](https://github.com/gajsin/avel/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=flat-square)](LICENSE)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2010%2F11%20x64-blue?style=flat-square)](https://github.com/gajsin/avel)

**Avel** — быстрая, лёгкая и единая системная утилита для Windows 10/11 x64, объединяющая шесть ключевых повседневных сценариев в одном автономном приложении: историю буфера обмена и скриншотов, мониторинг недавних файлов и папок, координатор темы и обоев рабочего стола, управление скрытием рабочего стола, аппаратное управление яркостью мониторов и гибкие системные настройки.

---

## Основные возможности

### 1. Буфер обмена и Снимки экрана («Буфер»)
- **Событийный перехват**: отслеживание изменений буфера в реальном времени через message-only окно Win32 (`WM_CLIPBOARDUPDATE`) без постоянного опроса.
- **Поддержка форматов**: текст, ссылки, сниппеты кода и полноцветные изображения с альфа-каналом (`CF_UNICODETEXT`, `CF_DIBV5`, `CF_DIB`).
- **BLAKE3-дедупликация**: моментальный попиксельный подсчёт хеша и защита от зацикливания при повторной вставке.
- **Автозахват скриншотов**: выровненное безопасное слежение за системной папкой снимков экрана через `ReadDirectoryChangesW` с фильтрацией дубликатов.
- **2 режима отображения**: Подробная таблица и Сетка с сохранением выбранного режима для каждого фильтра.
- **Quick Look**: встроенный быстрый просмотр по нажатию клавиши `Пробел` с навигацией стрелками.

### 2. Недавние файлы и папки («Недавнее»)
- **COM STA наблюдатель**: фоновый поток отслеживает закрываемые окна и вкладки Проводника через `IShellWindows` с фильтрацией навигации внутри одного окна.
- **Интеллектуальные ярлыки**: чтение `.lnk` через `IShellLinkW` / `IPersistFile` с учётом активности окон Проводника.
- **Нативные миниатюры Shell**: кэширование системных иконок и превью файлов через `IShellItemImageFactory`.
- **Быстрый доступ**: список недавних элементов с фильтрацией по категориям (Все, Файлы, Папки, Избранное), быстрым открытием файла или расположения в Проводнике.

### 3. Оформление и Обои («Оформление»)
- **Тема Windows**: мгновенное переключение Светлой / Тёмной системной темы или работа по расписанию.
- **Синхронизация обоев**: раздельная привязка фоновых рисунков для светлой и тёмной темы через COM-интерфейс `IDesktopWallpaper`.
- **Координатор переходов**: сериализованная очередь сохранения с защитой от гонок и повторным согласованием (draft rebase) при асинхронных ответах.

### 4. Чистый рабочий стол («Рабочий стол»)
- **Скрытие значков**: скрытие и восстановление окна списка иконок рабочего стола (`SysListView32`) с сохранением видимости `SHELLDLL_DefView` и обоев.
- **Скрытие панели задач**: управление автоскрытием и видимостью панели задач (`Shell_TrayWnd`) с сохранением исходного системного состояния.
  > *Примечание:* На Windows 11 поведение дополнительных панелей на вспомогательных мониторах зависит от сборки ОС; утилита сохраняет и восстанавливает базовое состояние основной панели задач.
- **Восстановление при запуске и выходе**: сохранение исходного состояния в БД до применения настроек и попытка возврата при штатном выходе или перезапуске.

### 5. Управление яркостью («Яркость»)
- **Аппаратное управление DDC/CI**: прямое управление внешними мониторами через VCP-код `0x10` (Low-Level / High-Level Monitor API). Требует аппаратной поддержки монитора и подключения через DisplayPort/HDMI.
- **Поддержка встроенных экранов WMI**: управление яркостью экранов ноутбуков через пространство имен WMI (`WmiMonitorBrightnessMethods`).
- **Идентификация устройств**: вычисление стабильного ID монитора на основе имени устройства, описания и индекса (`device_name:desc:phys_idx`) с проверкой совпадения идентификатора перед отправкой команд.
- **Очередь запросов**: объединение последних целевых значений и сохранение журнала восстановления тестовой сессии (`brightness_test_recovery`).

### 6. Настройки и Жизненный цикл («Настройки»)
- **Интерфейс**: светлая, тёмная или системная тема приложения, выбор языка (Русский / English).
- **Автозапуск**: интеграция в автозагрузку Windows через системный плагин (`--minimized`).
- **Глобальные хоткеи**: 7 настраиваемых системных комбинаций клавиш (Буфер, Недавнее, Рабочий стол, Оформление, Яркость +, Яркость -, Экран яркости) с валидацией и сохранением настроек.
- **Трей**: тихое сворачивание в область уведомлений при закрытии (`X`), запрет повторного запуска (Single Instance).

## Конфиденциальность и безопасность

- **100% Offline**: приложение не делает никаких сетевых запросов, не содержит аналитики, трекеров и телеметрии.
- **Локальное хранилище**: база данных SQLite в режиме WAL хранится в каталоге данных приложения (`%APPDATA%\com.avel.utility\avel.db`).
- **Изоляция данных**: все сохранённые изображения и миниатюры хранятся локально в профиле пользователя с проверкой путей перед удалением.

## Установка

Готовый установщик доступен в разделе [Releases](https://github.com/gajsin/avel/releases):

1. Перейдите на страницу [Релизов](https://github.com/gajsin/avel/releases/latest).
2. Скачайте официальный установщик: **`Avel_1.2.4_x64-setup.exe`**.
3. Запустите установщик и следуйте простым инструкциям мастера установки.

---

## Сборка из исходников

Для самостоятельной сборки потребуется:
- **Node.js** 20+
- **Rust** stable (MSVC toolchain, проверено на 1.97+)
- **Visual Studio C++ Build Tools** (компоненты C++ x64/x86)

```bash
# 1. Клонирование репозитория
git clone https://github.com/gajsin/avel.git
cd avel

# 2. Установка зависимостей фронтенда (locked)
npm ci

# 3. Запуск проверок фронтенда
npm run typecheck

# 4. Запуск проверок бэкенда
cargo test --manifest-path src-tauri/Cargo.toml --locked --all-targets

# 5. Сборка релизной версии и установщика
npm run tauri -- build
```

Собранный установщик будет находиться в каталоге:
`src-tauri/target/release/bundle/nsis/Avel_1.2.4_x64-setup.exe` (или `bundle/msi/`).

## Стек технологий

- **Десктопное ядро**: [Tauri 2](https://v2.tauri.app/) + [Rust](https://www.rust-lang.org/)
- **Интерфейс**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- **Хранение данных**: SQLite через [rusqlite](https://github.com/rusqlite/rusqlite) (bundled)
- **Интеграция с Windows**: `windows-rs` и `windows-sys` (Win32 API, COM, GDI, Shell)
